# Descripción del Dataset - Aprendizaje No Supervisado (Clustering)

## 1. Contexto y Fuente de Datos
Para dar cumplimiento a los métodos de aprendizaje no supervisado (Agrupamiento / Clustering), se diseñó un dataset enfocado en las características operativas de las estaciones del sistema de transporte masivo. A diferencia del modelo supervisado anterior, aquí **no existen etiquetas previas o variables objetivo (*targets*)**; el algoritmo debe descubrir patrones de similitud por sí mismo.

## 2. Variables de Estudio
- **estacion**: Nombre identificador de la estación.
- **tiempo_espera_promedio_min**: Tiempo medio que un usuario espera en plataforma.
- **afluencia_pasajeros_diaria**: Volumen estimado de pasajeros que transitan por la estación cada día.
- **distancia_promedio_km**: Distancia operativa media con respecto a las estaciones adyacentes.
